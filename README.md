## What it does

`main.py` writes one short, funny rant (396 characters) to
`/output/entry.txt`: the smoke alarm that only ever dies at 3 a.m.,
chirping like a cricket with a grudge while you stand barefoot on a
chair pressing a button that has never once, in the history of
buttons, done anything.

The text is inside the gate's 1–400 character limit, and the program
is deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
